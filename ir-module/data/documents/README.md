# Sample policy corpus

These documents are **illustrative sample content written for the IT3041 assignment**. They are not real utility
policies. The four original documents (leak detection, drought response, water quality, complaint handling) came
with the project; the remaining seven were added so retrieval has a corpus large enough to be meaningful.
Figures such as thresholds and response times are placeholders.

Before any real use, replace them with the utility's actual policies and have a domain expert verify them.
Only `.txt` files are indexed. The first non-empty line of each file is its title.
